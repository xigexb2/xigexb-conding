# 嵌入式、固件与 RTOS

## EMB01 平台与边界

- 明确 MCU/SoC、核、板卡版本、时钟树、内存图、外设、电源和启动方式
- BSP、HAL、驱动、协议、领域状态与应用编排分层，接口反映外设能力和资源生命周期
- 使用厂商手册、勘误与实际芯片版本，不根据同系列名称假设寄存器兼容
- RTOS 与裸机策略依据实时性、RAM/Flash、认证约束和维护成本选择，不盲目迁移语言或调度器

## EMB02 实时与资源

- 任务定义优先级、周期、最大执行时间、deadline、栈与阻塞预算
- 最坏执行时间、抖动和抢占行为需要测量与分析，平均吞吐不能证明硬实时
- 中断快速确认和搬运必要数据，重工作下放任务；使用中断安全接口
- 任务间通信有界，定义丢弃、覆盖、阻塞和失效策略，避免无界采样缓存
- 动态分配、日志、Flash 擦写和网络操作对实时路径的影响明确
- Watchdog 由真实健康条件喂养，不能靠一个永久循环掩盖关键任务死锁
- 堆栈水位、溢出、句柄数、缓冲池和队列高水位具有观测与恢复策略

## EMB03 驱动与外设

- 寄存器位宽、读改写副作用、读清/写一清零与访问顺序按手册实现
- DMA 缓冲满足可达内存、对齐、cache clean/invalidate 和所有权交接要求
- UART/SPI/I2C/CAN 等处理超时、总线错误、重新初始化和共享总线仲裁
- 时间基准区分 tick、硬件 timer、RTC 和单调时间，检查回绕与低功耗暂停
- 非易失写入考虑擦写寿命、掉电原子性、CRC、版本及双区/日志方案
- 引脚复用、上拉、电平、启动脚和调试口与原理图一致，不以代码默认配置猜测板卡

## EMB04 启动与升级

- 启动代码、链接脚本、向量表、栈和堆布局与实际二进制核对
- Bootloader、应用与配置有版本和兼容契约，校验镜像完整性与来源
- 评估安全启动、A/B、回滚保护、失败计数和恢复通道，依据硬件能力实现
- 升级中断电、空间不足、通信中断、签名错误和降级请求有验证场景
- 不把旧 C ABI 依赖当成可以自动消除的实现细节；重写前检查二进制库、启动和调度器依赖

## EMB05 板级验证

- 提供电源、时钟、下载、串口与外设的可复现板测步骤和预期证据
- 频点索引、频率、带宽、功率和调制参数分别标注，不能混用单位
- 检查复位原因、欠压、温度、长时间运行、通信恢复和资源水位
- 主机单测、固件链接、仿真、硬件在环及真实板卡验证分别记录
- 未连接板卡时只交付可验证的构建与分析，不宣称射频、时序和板级功能通过
