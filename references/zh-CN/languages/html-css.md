# HTML、CSS 与浏览器布局

[English](../../languages/html-css.md) | **简体中文** | [规范索引](../translations.md)

所有包/目录直接同类源码最多 20 个，测试、声明与第一方生成文件合并计数；设计时按职责划分子包，遵守 [统一目录规范](../directory-structure.md)

- HTML 使用语义元素，按钮执行动作、链接导航、表单控件有真实 label
- 原生控件能够表达时优先复用，ARIA 不代替缺失的键盘与状态行为
- DOM 顺序与阅读和键盘顺序一致，避免用 CSS 视觉排序制造操作混乱
- CSS 使用项目主题 tokens、布局尺度和断点，不在页面随意复制颜色与尺寸
- 优先 Grid/Flex 和正常文档流，避免大量绝对定位适配固定截图
- 尺寸根据内容和容器设计，处理长中文、英文长词、数字、RTL 和文字放大
- 焦点可见，hover 不是唯一反馈；触屏、键盘、鼠标都有可完成的主流程
- 媒体有尺寸或纵横比，避免布局跳动；按语义提供替代文本
- 动效尊重 reduced-motion，颜色尊重系统主题与对比度需求
- 层叠、弹层和 z-index 有统一尺度，正确处理焦点圈、滚动锁定和退出后焦点恢复
- 使用容器查询、`:has()` 等新能力前核对浏览器支持及降级
- 表单自动填充、输入类型、输入模式、错误关联及国际化按真实业务设置
- HTML/CSS 格式用仓库工具，手工源文件最多 380 行；大页面按稳定组件边界拆分

结合 [UI 与交互](../product/ui-ux.md)、[设计体系](../product/design-systems.md)、MDN 与 WCAG 执行。
