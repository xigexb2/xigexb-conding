## PY01 可读性与类型

- 以 `pyproject.toml`、支持版本与依赖锁为准，单文件最多 380 行
- 采用 PEP 8 与 PEP 257，默认四空格；中文 docstring 描述契约与失败行为
- 公开 API 和复杂数据流使用类型标注；类型检查不等于运行时输入校验
- 使用 dataclass、TypedDict、Protocol 等表达实际数据模型，不强制引入校验框架
- 避免可变默认参数、隐式全局状态、导入时网络访问和复杂多层推导式
- 区分文本与字节，明确编码、时区、Decimal 精度和序列化边界

## PY02 错误与资源

- 捕获具体异常，增加上下文用 `raise ... from ...` 保留因果链
- 不用裸 `except` 或 `except Exception: pass` 吞掉失败；退出与取消信号不能静默忽略
- 文件、连接、锁和临时资源使用上下文管理器；失败时完成必要的回滚与清理
- 外部命令使用参数列表并检查退出状态，默认不用 shell；不把用户输入拼进命令
- 路径使用 `pathlib`，校验解析后的边界；防范符号链接、目录穿越和检查后使用竞争
- 不反序列化不可信 pickle，不使用 eval/exec 解析业务输入

## PY03 异步与并发

- `asyncio` 适用于协作式 I/O，不在事件循环直接运行阻塞库或长 CPU 计算
- `TaskGroup` 等功能以最低 Python 版本为准，父子任务与异常组按实际契约处理
- 每个创建的任务有监督者；取消后正确等待清理，不留下无人观察的异常
- 捕获取消只为清理，按契约继续传播；用 `shield` 时说明取消后工作和资源的归属
- 线程池、进程池和并发请求数量有界；不可假定取消 await 就停止已启动的线程工作
- 不依赖 GIL 保护业务复合操作；解释器和 free-threaded 构建的并发能力按实际版本判断
- 多进程明确序列化、启动方式、共享内存和子进程退出，不能只验证 fork 环境

## PY04 性能与依赖

- 大文件使用流式迭代与有界批处理，避免一次读入和大型临时列表
- 预编译或缓存解析结果前确认热点与容量；生成器也要管理其持有的文件资源
- 使用标准库与项目已有库，不为少量功能导入大型运行时
- 虚拟环境隔离，区分直接依赖和开发依赖，使用项目选定的锁定与安装工具
- 用 cProfile、采样分析和适用基准定位问题；必要时评估向量化、进程或原生扩展

## PY05 验证

```text
python -m compileall -q src
python -m unittest discover -s tests
```

- 命令按目录与框架调整；已有 pytest、Ruff、mypy/pyright 配置则复用
- 测试覆盖输入边界、错误、资源清理和异步取消，纯文本改动不写镜像测试
- 测试临时路径隔离，不读取用户真实配置和凭据；测试结果不依赖外部生产服务
- 运行与最低支持版本相容的语法和依赖矩阵
